# سامانه رزرو آنلاین نانوایی — فاز آزمایشی

یک پلتفرم سه‌قسمتی (همه به یک Backend مشترک متصل‌اند):

| بخش | مسیر | چه کسی |
|---|---|---|
| 🍞 اپ مشتری | `/` | رزرو نوبت، مدیریت نوبت‌ها |
| 🥖 پنل نانوا | `/bakery` | تأیید نوبت، ظرفیت روزانه، تحویل |
| 🛠 پنل مدیریت | `/admin` | ثبت نانوایی، رمز نانوا، آمار |

## نصب و اجرا

```bash
pip install -r requirements.txt
python app.py
```

باز کنید: `http://localhost:5000`

## حساب‌های پیش‌فرض (آزمایشی)

| نقش | نام کاربری | رمز |
|---|---|---|
| مدیر | `admin` | `admin123` |
| نانوا (نمونه) | `rezaei` یا `pourmand` | `test123` |
| مشتری | — | ورود با OTP (شماره موبایل) |

> رمز نانواها را می‌توانید از پنل مدیریت تغییر دهید یا برای نانوایی جدید تعیین کنید.

## سرویس پیامک

- در حالت آزمایشی (`MOCK_SMS = True` در `sms.py`) کد تأیید در **فایل `sms_log.txt`** ذخیره می‌شود و پیام واقعی ارسال نمی‌شود.
- برای اتصال واقعی (Kavenegar): `MOCK_SMS` را `False` کنید و `KAVENEGAR_API_KEY` را پر کنید.

## جریان اصلی (فاز آزمایشی)

1. مدیر وارد پنل `/admin` می‌شود و نانوایی + نام کاربری/رمز نانوا ثبت می‌کند.
2. نانوا با رمز خود در `/bakery` وارد می‌شود، ظرفیت امروز را تعیین و نوبت‌ها را تأیید/تحویل می‌کند. اگر پذیرش را ببندد، نانوایی «بسته» اعلام می‌شود.
3. مشتری در `/login` با شماره موبایل و OTP وارد می‌شود، نانوایی را روی نقشه پیدا می‌کند و نوبت می‌گیرد و از «نوبت‌های من» مدیریتش می‌کند.

## ساختار پروژه

```
app.py              ورودی + ثبت Blueprint ها
models.py           همه مدل‌های دیتابیس
seed.py             داده‌های اولیه + حساب مدیر
sms.py              سرویس پیامک (mock / Kavenegar)
customer_routes.py  اپ مشتری
bakery_routes.py    پنل نانوا
admin_routes.py     پنل مدیریت
templates/          قالب‌های HTML (فارسی، راست‌چین)
static/             CSS و JS
```

## نکته‌ها

- کنترل ظرفیت و قیمت‌گذاری فقط در Backend انجام می‌شود.
- جلوگیری از رزرو تکراری (هر شماره یک نوبت فعال در هر روز) فعال است.
- دیتابیس: SQLite (`bakery.db`). در نسخه تولیدی به PostgreSQL + PostGIS منتقل می‌شود.
- نقشه: Leaflet + OpenStreetMap.

## قابلیت‌های نسخه فعلی (جدید)

- **تقویم شمسی** — همه تاریخ‌ها (صفحه تأیید، نوبت‌های من، پنل نانوا) با تقویم جلالی و اعداد فارسی نمایش داده می‌شوند (`utils.py`).
- **QR کد تحویل** — مشتری در صفحه تأیید و در «نوبت‌های من» (دکمه «نمایش QR») کد تحویل را به صورت QR دارد؛ نانوا با وارد کردن کد یا خواندن QR تحویل را ثبت می‌کند.
- **اعلان داخلی** — زنگوله در هدر با شماره نوبت‌های «آماده» (هر ۲۰ ثانیه به‌روزرسانی می‌شود) + بنر «نان شما آماده دریافت است» در کارت نوبت.
- **مدیریت ظرفیت ۷ روز آینده** — نانوا برای هر روز جداگانه ظرفیت و پذیرش را تعیین می‌کند؛ این تنظیم برای امروز و روزهای آینده اعمال می‌شود (بستن پذیرش روز آینده هم رزرو همان روز را مسدود می‌کند).
- **تست خودکار** — `python test_features.py` همه ۱۹ سناریو (ورود، رزرو، QR، اعلان، ظرفیت، بستن روز) را بررسی می‌کند.
- **نصب به‌صورت اپ (PWA)** — سایت روی اندروید/ویندوز به‌صورت اپ قابل نصب است (بخش بعدی).

## 📲 نصب برنامه (PWA)

سایت به‌صورت Progressive Web App است؛ یعنی بدون نیاز به استور، روی گوشی و ویندوز مثل یک اپ واقعی نصب می‌شود:

### اندروید (کروم)
1. سایت را با کروم باز کنید (`http://آدرس-سرور:5000`)
2. بالای صفحه بنر «⬇ نصب برنامه روی دستگاه شما» را بزنید، یا از منوی ⋮ گزینه **Add to Home screen / Install app** را انتخاب کنید
3. آیکون 🍞 نانوایی روی صفحه گوشی اضافه می‌شود و مثل اپ مستقل (بدون نوار مرورگر) باز می‌شود

### ویندوز (کروم / اج)
1. سایت را باز کنید
2. در نوار آدرس آیکون «Install» (یا منوی ⋮ → **Install سامانه رزرو آنلاین نانوایی**) را بزنید
3. برنامه به‌صورت پنجره مستقل نصب و در Start Menu ثبت می‌شود

### فایل‌های PWA
- `static/manifest.json` — مشخصات اپ (نام، آیکون، رنگ، حالت standalone)
- `static/sw.js` — Service Worker برای کش اولیه (باز شدن سریع‌تر)
- `static/icons/` — آیکون‌های ۱۹۲ و ۵۱۲ (با اسکریپت قابل بازتولید هستند)
